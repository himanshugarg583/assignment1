# Firstpoint Logistics

Cinematic logistics and transport website built with a modern React stack, premium UI, and advanced motion.

## Tech Stack
- React + Vite + TypeScript
- Tailwind CSS
- Framer Motion, GSAP, Lenis smooth scroll
- Radix UI with Shadcn-style components
- Lucide icons

## Commands
- npm run dev
- npm run build
- npm run preview
- npm run lint

## Project Structure
- src/app/pages
- src/components
- src/animations
- src/hooks
- src/lib
- src/styles
- src/data
- public
